Overview

This Todo and Note-taking application is a demonstration of a modern, full-stack web application. It is designed to be robust, secure, and user-friendly, showcasing a clean architecture and responsive design.

Frontend

  • HTML5 & CSS3 Semantic structure and styling
  • Tailwind CSS Utility-first CSS framework for rapid UI development
  • Vanilla JavaScript Core logic for UI updates and API interaction

Backend

  • Node.js Runtime environment
  • Express.js Web framework for handling routes and requests
  • MongoDB NoSQL database for data persistence
  • Mongoose ODM for modeling application data

Key Features

✅ Dynamic Checklists

Transform simple notes into interactive checklists. Completed items automatically move to the bottom.

📸 Image Attachments

Enhance your tasks by uploading images directly to any list item. View them in full-screen detail.

🤝 Real-time Sharing

Collaborate with others by sharing notes. Control access with Read-Only or Edit permissions.

🛡️ Secure Authentication

User data is protected with JWT sessions and bcrypt password hashing. Guest mode available for quick access.

Methodology

RESTful API Architecture

The application follows REST principles, separating client and server concerns. The backend exposes standard HTTP endpoints (GET, POST, PUT, DELETE) which the frontend consumes asynchronously.

Security & Authentication

Security is a priority. Passwords are hashed using bcrypt before storage. Session management is handled via JSON Web Tokens (JWT), ensuring stateless and secure authentication flow. Role-based access control (RBAC) is implemented to distinguish between standard users and administrators.

Responsive Design

The UI is built Mobile-First using Tailwind's responsive modifiers, ensuring a seamless experience across devices from mobile phones to desktops.
